## 2. Descripción del Sistema

El sistema Lufra-2020 es una aplicación web desarrollada como proyecto académico. Presenta una arquitectura de frontend moderno (Vue.js/JavaScript/TypeScript) que interactúa con un backend robusto (PHP/Laravel). La app está diseñada para ejecutarse en un entorno de servidor web local en desarrollo o en servidores de producción compatibles.

---

## 3. Requisitos del Sistema

### 3.1 Requisitos de Hardware

- Procesador: 1 GHz o superior
- RAM: al menos 2 GB
- Espacio en disco: mínimo 500 MB libres

### 3.2 Requisitos de Software

- **Servidor web:** Apache o Nginx
- **PHP:** Versión 7.4 o superior
- **Composer:** Última versión
- **Node.js y npm:** Node.js v14 o superior, npm v6 o superior (o Yarn)
- **Base de datos:** MySQL/MariaDB (según configuración)
